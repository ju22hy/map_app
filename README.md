# 🗺️ map_app - 위치 기반 도서관 정보 조회 실습

이 프로젝트는 JavaScript와 네이버 지도 API를 활용하여,  
현재 위치를 기반으로 주변 도서관 정보를 지도에 시각화한 실습 프로젝트입니다.

## 🌟 주요 기능
- 현재 위치를 기준으로 지도 표시
- 조건에 맞는 도서관 데이터를 필터링하여 마커 생성
- 마커 클릭 시 인포윈도우 + 하단 상세 정보 박스 표시
- 상세 정보에는 도서 자료 수, 운영시간, 주소, 연락처, 홈페이지 등 포함
- 하단 정보 박스는 아이콘 클릭 시 슬라이드로 열고 닫을 수 있음

## 🛠️ 사용 기술
- HTML / CSS / JavaScript
- 네이버 지도 API
- geolocation API
- DOM 조작 및 이벤트 핸들링
- 배열 필터링 및 객체 데이터 처리

## 💬 회고
- 처음으로 외부 지도 API와 위치 정보를 연동한 프로젝트로, API 사용법과 위치 기반 데이터 활용 방식을 익힐 수 있었습니다.
- 마커 클릭 시 데이터를 동적으로 전달하고, 이를 화면에 렌더링하는 과정을 통해 자바스크립트의 데이터 흐름을 더 잘 이해하게 되었습니다.
- 프로젝트를 진행하며 이벤트 흐름에 대한 실습 경험을 쌓였습니다.
